# 纯 Worker 环境兼容性

本实现为登录环境脚本提供 DOM 和 CPU Canvas 2D，不是完整浏览器。普通 Cloudflare Worker 不包含 Chromium；Cloudflare Browser Run 是独立的托管浏览器服务，本分支未绑定它。

## 已实现和验证的范围

| 能力                      | 实现与证据                                                                                  | 边界                                                                             |
| ------------------------- | ------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| HTML / DOM                | QuickJS 内运行 LinkeDOM，实际维护节点、属性、选择器、克隆、增删和事件冒泡                   | 不承诺覆盖浏览器全部 DOM API                                                     |
| Canvas 2D                 | Skia CanvasKit WASM 实际绘制像素、路径、渐变、文字；支持读取像素、PNG、尺寸重置和跨画布绘制 | 以 CanvasKit 的 Canvas 2D 子集为限                                               |
| 字体                      | 内置 Arimo、Tinos、Cousine 的 Latin 常规字体；真实测量字宽并栅格化                          | 无完整系统字体、中文/emoji 回退、复杂文字塑形；替代字体不等于 Windows/macOS 字体 |
| DOM 尺寸                  | 基础内联样式、简单样式表、继承和字体测量                                                    | 无完整 CSS 排版、级联优先级、Flexbox、Grid 或页面渲染                            |
| Storage / Cookie          | 每次执行独立保存键值与简单 Cookie 状态                                                      | 不导入账号 Cookie；不是完整浏览器存储模型                                        |
| 异步                      | Promise、定时器、微任务与虚拟时间顺序                                                       | 有执行预算，不模拟真实浏览器事件循环的所有细节                                   |
| Intl / 随机数             | 有范围限制的 JSON 桥接；使用宿主 Intl 和安全随机数                                          | 只暴露白名单操作，不暴露宿主对象                                                 |
| WebGL / WebGPU / WebAudio | 未实现                                                                                      | WebGL 上下文返回 null；没有伪造 GPU 像素                                         |
| 网络与 TLS                | Worker 原生 fetch；平台动态脚本内没有网络权限                                               | 无法通过 fetch 配置上游 Go 客户端的 Chrome TLS / HTTP2 指纹                      |

CanvasKit 的文字对齐、基线、TextMetrics 等也不保证与 Chromium 一致。报错会结束当前环境校验，不能以伪造固定图片或固定尺寸作为兼容性通过依据。

## 隔离和资源范围

平台脚本只在 QuickJS 中运行，宿主桥接仅传 JSON 和数字句柄。没有宿主网络、文件、进程或环境变量权限，不接收管理员口令、加密密钥或账号 Cookie。

- QuickJS 堆上限 32 MiB，栈上限 512 KiB；有指令、任务、定时器及结果大小限制。
- 同时最多 16 张画布，单边最多 2048，单画布最多 1048576 像素，总画布最多 2097152 像素。
- Canvas 命令最多 20000 次；单次像素读取最多 65536 像素；跨画布图片解码有累计次数和像素预算。
- 每次结束释放画布和相关对象；字体注册保留在当前 Worker 实例中供后续调用复用。

32 MiB 是 QuickJS 堆限制，**不是整个 Worker 的内存上限**；CanvasKit、宿主字符串和图像还会使用其他内存。这些应用预算也不能替代 Cloudflare 的 CPU 与内存限制。

## 尚未解决的登录问题

最近一次真实手机确认仍返回错误码 `7`，没有保存登录态。新环境能执行缓存的真实环境脚本，但没有新版本的完整真实登录证据。

令牌报告与其他 SDK 参数仍使用上游预设档案，而当前 Canvas 使用实际 Skia 输出；跨 SDK 的环境一致性尚未完成。不同 SDK 的画图方法不同，不能直接拿一个测试画布的 hash 替换所有报告。TLS、字体、屏幕参数或其他差异都不是已经证实的拒绝原因。

真实登录、读取本人推荐、取消并复核移除，以及重启后恢复会话全部成功，才算业务验收通过。测试明细见 [验证记录](protocol-verification.md)。
