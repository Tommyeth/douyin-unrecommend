调度入口验收是 CLI 手动触发 Schedules 后端，并非等待自然定时触发的测试。部署的调度表达式为 `*/15 * * * *`；Vercel Hobby 的调度抖动意味着执行时间不保证精确相隔 15 分钟。

旧会话在本轮开始时已失效，转换没有覆盖原状态；用户重新扫码后完成上述验收。旧版全程浏览器的历史结果见 [原验收记录](vercel-verification.md)。本记录的 Vercel 出口实测独立于 Cloudflare 的历史结果。

## 页面控制与自动化验证

- 真实 Vercel 页面已显示二维码，点击输入框、输入测试文字、全选和删除均实测生效；测试文字已清空。用户随后完成实际身份验证。
- 全屏控制层让画面完整处于可视区，支持键盘、粘贴、滚动和拖动。操作经截图与请求转发，有延迟，不是常驻 VNC。
- 登录截图短暂失败时恢复抓图，保留原页面；无头浏览器恢复焦点后输入可达。
- 本地测试覆盖关闭 Chromium 后再请求协议接口、跨函数恢复、取消后复核、候选重试、账号不一致保护、失效时停止抖音请求，以及远程输入完整流程。
- 通知设置测试覆盖鉴权、加密存储、密钥不回显、编辑保留密钥、移除渠道，以及登录失效通知失败后由调度重试而不重新请求抖音。
- GitHub CI 包含 Node 原生模块加载、Worker / D1 回归及 Docker noVNC 集成测试。

登录失效通知采用模拟失败响应验收，未主动使生产登录态失效，也未向用户发送测试消息。Bark 的真实手机投递属于此前通知测试；其他渠道仍需使用客户自己的地址实测。

验收证明本次账号与出口可以工作，不保证登录永久有效或第三方接口永不变化。Cookie、签名、短信内容和账号标识不写入公开记录。返回 [部署说明](vercel.md)。
