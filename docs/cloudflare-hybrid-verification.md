## 本次修复

Wrangler 会在构建时把裸写的 `navigator.userAgent` 替换为 `Cloudflare-Workers`。登录采集函数需要序列化到 Chromium 执行，受此替换影响，原先保存了错误的 User-Agent，纯 HTTP 请求返回 HTTP 200 空响应。

现在使用 `window.navigator.userAgent` 读取远端浏览器值，并加入模拟同等构建替换、再序列化执行的回归测试。已保存的测试会话依据同账号真实浏览器请求修正标识，无需再次扫码；随后本机纯 HTTP 和线上 Worker 均验证通过。

客户端参数只保留稳定的浏览器信息，不把推荐接口的空 `device_platform` 复制到本人资料接口；推荐列表采用官方页面本次观测到的 `from=1`。签名和令牌按每次请求生成或轮换，不重放旧签名。
